# Portal DEMO · Automatización

Demostración de un portal de automatización de procesos para negocios
(reportes de ventas, cuadres, catálogo, etc.).

**Datos 100% de ejemplo — no contiene información real.**

- Acceso de prueba: usuario `demo` · contraseña `demo123`
- Hecho con Streamlit.

Ejecutar en local:

```
pip install -r requirements.txt
streamlit run demo_app.py
```
